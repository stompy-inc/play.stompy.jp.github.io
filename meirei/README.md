# 命令運命 // ORDERED FATE

楽曲が完全に終わるまで続く、三人称視点の3Dランナー・シューティングゲームです。

## 起動

このフォルダでローカルWebサーバーを起動し、表示されたURLをブラウザで開いてください。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。

## 操作

- `A` / `D` または左右矢印: 移動
- `Space` / クリック: 射撃
- スマートフォン: 画面下のボタン

攻撃対象を破壊すると従順スコアが増え、人間性スコアが低下します。破壊せず避けることもできます。

## 歌詞の表示タイミング

`assets/lyrics.txt` を編集し、各行を `表示開始秒|歌詞` の形式で指定します。秒数は0.1秒単位です。

```txt
5.0|人を殺し、街を破壊する
6.0|ワタシは兵隊ロボット
7.3|ただプログラムに従う
```

空行と `#` で始まる説明行は無視されます。編集後はブラウザを再読み込みしてください。
