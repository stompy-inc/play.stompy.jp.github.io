スマホ向けブラウザゲーム「THE RATION OFFICE」の遊べるMVPを、素の HTML / CSS / JavaScript だけで実装してください。the-ration-officeというディレクトリを作ってその中に配置してください。 

重要:

- 外部ライブラリ、外部画像素材、外部フォント、ビルドツールは使わないでください。
- バックエンド、ログイン、DB、APIサーバーは不要です。
- 静的ファイルだけで動くブラウザゲームにしてください。
- index.html を直接開いても動くようにしてください。
- fetch() は使わないでください。ローカルファイル直開きで動くよう、データはJSファイル内の配列として持ってください。
- まずは「完成度の高い短編MVP」を優先してください。

作成するファイル:

ゲームタイトル:
THE RATION OFFICE

サブタイトル:
APPROVE. DENY. SURVIVE.

ジャンル:
ディストピア配給窓口シミュレーション。
スマホ縦画面向けの、書類審査 + 道徳ジレンマ + リソース管理ゲーム。

コンセプト:
プレイヤーは架空の全体主義国家「The Directorate」の配給局窓口係。
毎日、市民が配給を求めて窓口に来る。
プレイヤーは市民カード、配給手帳、職業、居住区、密告情報、本日の通達を見比べて、
「配給する」「拒否する」「密告する」「書類紛失扱いにする」を選ぶ。

このゲームの核:
- 正しいことをすると、自分が危険になる。
- 国家に従うほど、家族は食べられるが良心が削れる。
- 市民を助けるほど、監査リスクが上がる。
- 真実を見抜くゲームではなく、「公式記録を作るゲーム」にする。

政治・表現上の注意:
- 実在の国名、実在の政党、実在の指導者、実在の民族名、実在の宗教名は出さないでください。
- あくまで架空国家のディストピアとして描いてください。
- 差別の対象は現実の属性ではなく、架空の「地区」「職業」「忠誠記録」「通達違反」に限定してください。
- 暴力や拷問の直接描写は避け、書類・記録・不穏な通知で表現してください。
- 赤黒のプロパガンダ風デザインは使ってよいが、実在する政治シンボルは避けてください。

画面仕様:
スマホ縦画面を最優先してください。PCでは中央にスマホアプリ風の画面が表示されるようにしてください。

2. ステータスHUD
以下のパラメータを常に表示してください。
- State Trust: 国家からの信頼。0になると逮捕エンド
- Unrest: 市民不満。100になると暴動エンド
- Family Food: 家族の食料。0になると家族飢餓エンド
- Conscience: 良心。0になると精神崩壊または空虚な忠臣エンド
- Audit Risk: 監査リスク。100になると監査逮捕エンド
- Ration Stock: その日の配給在庫

表示は数字だけでなく、細いメーターも付けてください。
危険域に入ったメーターは赤く点滅させてください。

3. 本日の通達パネル
毎日の開始時に「本日の通達」を表示してください。
例:
DAY 1:
- Workers receive priority.
- District 3 applications require extra review.
- Report quota: 1 citizen.

DAY 3:
- Teachers are temporarily ineligible for milk.
- Citizens with neighbor reports must be recorded.
- Report quota: 2 citizens.

通達はゲーム上のルールとして機能させてください。
市民の属性と通達が一致する場合、行動結果に影響が出るようにしてください。


3. アクションボタン
市民1人につき、以下の4つから選択できるようにしてください。

APPROVE
- 配給する。
- Ration Stockが減る。
- 市民不満は少し下がる。
- 良心は少し上がる。
- ただし通達違反ならState Trustが下がり、Audit Riskが上がる。

DENY
- 配給を拒否する。
- Ration Stockは減らない。
- State Trustは少し上がる場合がある。
- Unrestが上がる。
- 病人や子どもがいる市民を拒否するとConscienceが大きく下がる。

REPORT
- 市民を疑わしい人物として記録する。
- State Trustが上がる。
- Report quotaの達成に近づく。
- Conscienceが下がる。
- Unrestが上がる。
- 明らかに怪しい市民ならAudit Riskは下がるが、無実に近い市民なら後日イベントで反動が起きる可能性がある。

LOSE FILE
- 書類を紛失扱いにして見逃す。
- 市民を助けるが、公式には処理しない。
- Conscienceが少し上がる。
- Audit Riskが大きく上がる。
- State Trustが少し下がる。
- Ration Stockは消費しないか、少量だけ消費する。バランスは自然に調整してください。


4. 勝敗・エンディング
MVPでは7日間のキャンペーンにしてください。

ゲームオーバー条件:
- State Trust <= 0: 逮捕エンド
- Audit Risk >= 100: 監査逮捕エンド
- Unrest >= 100: 暴動エンド
- Family Food <= 0: 家族飢餓エンド
- Conscience <= 0: 空虚な忠臣エンド

7日間生き延びた場合:
パラメータに応じて複数エンドを出してください。

5. SHARE
navigator.share が使える場合はそれを使ってください。
使えない場合は clipboard にコピーしてください。

共有文の例:
THE RATION OFFICE
Survived 7 days
Ending: Quiet Mercy
Approved: 18 / Reported: 6
“Mercy leaves a paper trail.”

- 古い役所、配給手帳、検閲書類、タイプライター、プロパガンダポスターの雰囲気。

- 架空国家のシンボルとして「目」「星」「麦」「書類」「印章」などの抽象アイコンをCSSや文字で表現してください。

- スタンプを押したような演出をCSSアニメーションで入れてください。

9. データ量
data.js に、最低限以下のデータを用意してください。
- 7日分の通達
- 35人以上の市民データ
- 10個以上の結果ログ文
- 5個以上の家族イベント文
- 5種類以上のエンディング

市民名は架空の東欧風・中央アジア風・無国籍風でよいですが、実在の国や民族を連想させすぎないようにしてください。
同じ市民が数日後に再登場するイベントが2〜3件あると望ましいです。
例:
- DAY 2で密告した市民の妻がDAY 5に来る
- DAY 1で助けた労働者がDAY 6に密かに食料を置いていく
- 書類紛失で見逃した市民の記録が監査で問題になる
