# Lyric Starflight

`滅びかけの街で` の音源と歌詞を使った、ブラウザ用の3Dフライトゲームです。

## Play

ローカルサーバー経由で開くと遊べます。音声再生はブラウザの制限があるため、最初に `START` を押したタイミングで始まります。マウス、タッチ、矢印キー/WASD で機体を動かし、Space で加速します。奥から飛来する歌詞パネルに機体を通過させると、手前で歌詞が弾けてゲージが増えます。

## Lyrics Timing

`assets/lyrics.txt` は、時刻なしの通常歌詞でも動きます。その場合は曲の長さに合わせて均等に流れます。

細かく合わせる場合は、同じファイルを LRC 風の形式にします。

```txt
[00:06.50]星々は疾うに燃え尽きていた
[00:10.20]誰も、方角を信じなかった
```

秒数で手前に到達するタイミングを指定する場合は、`秒数|歌詞` の形式も使えます。
指定した時刻から逆算して、歌詞が奥から飛び出してきます。

```txt
5.0|星々は疾うに燃え尽きていた
7.3|誰も、方角を信じなかった
9.2|駅前の時計塔だけが
11.6|昨日のまま、時を閉ざしている
```
